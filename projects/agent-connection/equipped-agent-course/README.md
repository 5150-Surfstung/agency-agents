# The Equipped Agent — AI for Real Estate in One Hour

A one-hour course that teaches working agents three real AI skills and recruits for The AGENT Connection™ by teaching first and pitching last. Built with Surfstung Systems.

## What's in this package

| File | What it is |
|---|---|
| `course-outline.md` | The minute-by-minute facilitator run sheet, pre-flight checklist, and rules of engagement |
| `landing/index.html` | The full course as a scroll experience — published as a Claude artifact, posted to the group |
| `fb-post.md` | Facebook group launch kit: three post variants, the comment-keyword capture mechanic, and the follow-up DM script |

## The design in one paragraph

The course is the funnel. Sixty minutes: hook on the equipped/unequipped split (2025 NAR data), teach where AI actually pays, demo the Neighborhood Index (11-year MLS farming asset) and the grounded per-listing AI assistant (QR → answer → lead on the agent's phone in under 60s), hand over three working prompts, then one honest pitch at minute 55 with a three-rung commitment ladder (toolkit → Big REveal lunch → coffee/call). The Facebook version swaps the room's QR for a comment keyword — the commenter's own comment is the capture, and the follow-up DM inside the hour is the first speed-to-lead demo.

## Operating rules

- Never claim a number that can't be defended on real data. Everything on the page traces to the 2025 NAR member data or the eleven-year CHS Regional MLS series behind the published Neighborhood Index.
- Demos are live or clearly labeled replays. No faked confirmations.
- Every captured lead gets a response within the hour. Capture without follow-up is a dropped lead.
- Teach generously — the prompts are the ad.
